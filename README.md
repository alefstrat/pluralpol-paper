# pluralpol-paper
Code and data for the paper "Liberals and conservatives share overlapping interests but are increasingly divided within them".

## Note
Python analyses were conducted in version 3.12.3. Please double-check your Python version, as ordered dicts are required to derive the subreddit networks. *Your script may silently fail if you are using version 3.6 or older*.

 A `requirements.txt` file is available in the `/code` directory to recreate subreddit networks and embeddings.
